## Sistema de Pesquisa para Academia

Projeto desenvolvido em Java com o objetivo de simular uma pesquisa de academia, coletando informações dos usuários e gerando estatísticas ao final da execução.

## Funcionalidades

- Cadastro de participantes
- Leitura de:
  - Idade
  - Sexo
  - Objetivo do treino
  - Tempo de treino
- Cálculo de estatísticas:
  - Total de participantes
  - Média de idade
  - Menor idade informada
  - Maior tempo de treino
  - Objetivo mais escolhido
  - Sexo com mais participantes
  - Percentual de mulheres que desejam emagrecer
  - Quantidade de menores de 18 anos com mais de 12 meses de treino

## Conceitos praticados

- Estruturas condicionais (`if/else`)
- Laços de repetição (`while`)
- Contadores e acumuladores
- Cálculo de média e porcentagem
- Entrada de dados com `Scanner`
- Organização lógica de código

## Tecnologias utilizadas

- Java
- Eclipse IDE

## Objetivo do projeto

Praticar lógica de programação e manipulação de dados em Java através de um sistema simples de pesquisa e análise de informações.
